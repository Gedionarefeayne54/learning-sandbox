# Learning Sandbox

This repository is my personal learning journey through software development — a space where I practice, experiment, and track my progress as I build up skills from the ground up. It contains exercises, mini-projects, and notes from each stage of my learning path.

## 📚 Learning Path

### ✅ Web Development Foundation
Learned the core building blocks of the web:
- HTML structure, semantic tags, and forms
- CSS styling, box model, flexbox, and grid layouts
- Responsive design principles
- How browsers parse and render web pages
- Basics of version control with Git and GitHub

### ✅ Programming & JavaScript Foundation
Built a solid understanding of programming fundamentals and core JavaScript:
- Variables, data types, and operators
- Control flow (conditionals, loops)
- Functions, scope, and closures
- Arrays, objects, and common data structures
- DOM manipulation and event handling
- ES6+ features (arrow functions, destructuring, spread/rest, modules)
- Asynchronous JavaScript (callbacks, promises, async/await)

### ✅ Backend Development
Explored server-side development and how applications work behind the scenes:
- Node.js and server fundamentals
- Building RESTful APIs
- Handling HTTP requests and responses
- Working with databases (queries, CRUD operations)
- Authentication and basic security concepts
- Environment configuration and project structure

### ✅ React Development
Learned component-based UI development for building modern web apps:
- JSX syntax and component structure
- Props and state management
- React Hooks (useState, useEffect, and others)
- Conditional rendering and lists
- Handling forms and user input
- Building and structuring single-page applications (SPAs)

### 🔄 Currently Learning: Introduction to AI-Powered Application Development
Diving into how AI can be integrated into real applications:
- Understanding AI/LLM APIs and how to call them
- Prompt design and prompt engineering basics
- Building simple AI-powered features (chatbots, text generation, etc.)
- Connecting AI capabilities to frontend/backend applications
- Exploring use cases for AI in everyday software

## 🎯 Purpose

This repo serves as a running log and practice ground for each stage of my development journey — a place to consolidate what I've learned, revisit concepts, and build small projects that demonstrate each skill.

- **Backend:** Node.js, REST APIs, Databases
- **Tools:** Git, GitHub, VS Code
- **Currently exploring:** AI/LLM APIs

## 🚀 What's Next

Continuing to build on AI-powered application development, with plans to build small AI-integrated projects and deepen my understanding of how AI fits into full-stack development.
