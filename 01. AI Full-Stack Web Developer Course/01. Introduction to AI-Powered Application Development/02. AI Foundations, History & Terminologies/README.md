## ✨ Overview

This document is a reference guide covering the **foundations of Artificial Intelligence** — what it is, how it evolved, and the key terms you'll run into when studying or building AI systems.

## 📜 A Brief History of AI

| Era | Period | Highlights |
|---|---|---|
| 🌱 **Origins** | 1940s–1950s | Turing's "Can machines think?" (1950); the term *"Artificial Intelligence"* coined at the Dartmouth Conference (1956) |
| 🚀 **Early Optimism** | 1950s–1960s | First AI programs (Logic Theorist, ELIZA); symbolic reasoning and early neural nets (Perceptron) |
| ❄️ **First AI Winter** | 1970s | Funding cuts after inflated expectations weren't met |
| 💼 **Expert Systems Era** | 1980s | Rule-based "expert systems" used in business and medicine |
| ❄️ **Second AI Winter** | Late 1980s–1990s | Expert systems proved brittle and expensive to maintain |
| 📈 **Machine Learning Rise** | 1990s–2000s | Statistical learning, SVMs, and growing datasets shift focus from hand-coded rules to learned patterns |
| 🔥 **Deep Learning Boom** | 2010s | Deep neural nets + GPUs + big data → breakthroughs in vision (ImageNet), speech, and games (AlphaGo) |
| 🤖 **Generative AI Era** | 2020s | Large language models (GPT, Claude, etc.) enable chatbots, code generation, and multimodal AI |

## 🧩 Foundational Concepts

- **Artificial Intelligence (AI)** — The broad field of building systems that perform tasks normally requiring human intelligence.
- **Machine Learning (ML)** — A subset of AI where systems learn patterns from data rather than following explicit rules.
- **Deep Learning (DL)** — A subset of ML using multi-layered neural networks to learn complex patterns.
- **Natural Language Processing (NLP)** — The field focused on enabling machines to understand and generate human language.
- **Generative AI** — Models that create new content (text, images, code) rather than just classifying or predicting.

## 📖 Key Terminology

| Term | Definition |
|---|---|
| **Algorithm** | A step-by-step procedure for solving a problem or performing a computation |
| **Model** | The output of training — a mathematical representation that makes predictions |
| **Training Data** | The dataset used to teach a model patterns |
| **Neural Network** | A model architecture loosely inspired by the brain, made of layers of interconnected "neurons" |
| **Parameters / Weights** | The internal values a model learns and adjusts during training |
| **Training** | The process of adjusting a model's parameters using data |
| **Inference** | Using a trained model to make predictions on new data |
| **Supervised Learning** | Learning from labeled examples (input → correct output) |
| **Unsupervised Learning** | Finding patterns in data without labeled outputs |
| **Reinforcement Learning** | Learning by trial and error via rewards and penalties |
| **Overfitting** | When a model learns the training data too well and fails to generalize |
| **Tokens** | Chunks of text (words/subwords) that language models process |
| **Embedding** | A numerical (vector) representation of data that captures meaning/relationships |
| **Transformer** | A neural network architecture (introduced 2017) that underlies most modern LLMs |
| **LLM (Large Language Model)** | A large-scale transformer model trained on text to understand and generate language |
| **Prompt** | The input text given to a language model to elicit a response |
| **Fine-tuning** | Further training a pre-trained model on a specific, smaller dataset |
| **Hallucination** | When a model generates confident but incorrect or fabricated information |

## 🗺️ How the Pieces Fit Together

1. **Data** is collected and prepared.
2. A **model** (e.g., a neural network) is **trained** on that data, adjusting its **parameters**.
3. The trained model performs **inference** — making predictions or generating output on new inputs.
4. For language models, input/output is handled as **tokens**, often represented internally as **embeddings**.
